# Machine Learning Projects

Welcome to my Machine Learning repository! This repository showcases my hands-on learning and practical implementation of various machine learning concepts and techniques using Python and MATLAB.

The work focuses on understanding the complete machine learning workflow, from exploring and preprocessing datasets to building models, evaluating their performance, and analysing their behaviour.

## Overview

The repository covers various aspects of machine learning, including:

- **Data Preprocessing:** Cleaning datasets, handling missing values, removing duplicates, encoding categorical variables, and feature scaling.
- **Exploratory Data Analysis:** Understanding datasets through statistical analysis, visualizations, and correlation studies.
- **Machine Learning Algorithms:** Implementing and experimenting with classification algorithms such as Logistic Regression, K-Nearest Neighbors, Support Vector Machines, and Decision Trees.
- **Implementation from Scratch:** Understanding algorithm fundamentals by implementing techniques such as Logistic Regression and ID3 Decision Trees.
- **Model Evaluation:** Measuring model performance using accuracy, precision, recall, F1-score, and confusion matrices.
- **Anomaly Detection:** Identifying unusual patterns and suspicious observations using statistical methods and Isolation Forest.
- **Model Robustness:** Studying the impact of noise on model performance.
- **Fairness in Machine Learning:** Evaluating potential bias using fairness metrics such as Demographic Parity and Equal Opportunity.
- **Feature Selection and Ablation:** Understanding the contribution of individual features and their impact on model performance.
